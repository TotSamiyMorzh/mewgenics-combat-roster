# Changelog

Supported game build: Mewgenics 1.1.21239 (Steam build 25143593).

## 0.5.0 — 2026-10-02
- Real cat faces in their class colours, composed from the game's cat parts.
- SWF renderer: mask layers, part substitution, palette recolouring.

## 0.4.x
- Game icons for equipment, abilities, passives and effects; bigger icons with descriptions beside them.
- Scrollable unit tooltip (wheel) that doesn't scroll the party list; ability cost on the name line.
- Resizable list height; system cursor hidden over the panel; panel no longer blinks.
- Internal abilities without a name are hidden.

## 0.3.0
- The game's fonts, paper texture, inked HUD-style bars; opacity setting; list height cap with scrolling.
- The board under the panel no longer reacts to the mouse.

## 0.2.0
- Native art (portraits, heart/mana/stat/status icons) rasterised from the game's SWF files.
- Text in the game's language from its StringsDatabase; mana, stacks, ability costs; draggable panel.

## 0.1.0
- First version: party list, HP bars, tooltip, board highlight, collapse.
